# Known-audio pool

The V4 pipeline knows the metadata and preferred edit segments for these IDs:

- `te_conoci_super_slowed`
- `gozalo_super_slowed`
- `no_era_amor_super_slowed`
- `luz_roja_slowed`
- `luna_bala_slowed`
- `sempero_super_slowed`
- `passo_bem_solto_slowed`

If you are authorized to use a track, place the audio file here using the matching ID as the filename, for example:

`te_conoci_super_slowed.mp3`

The repository intentionally does not include or download copyrighted audio. `assets/music/*` is ignored by Git, so do not accidentally publish licensed/commercial audio in a public repository.
